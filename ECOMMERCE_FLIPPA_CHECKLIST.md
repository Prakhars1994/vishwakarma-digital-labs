# LUMACART — Sale Readiness Checklist

## Product
- [x] Custom multi-page ecommerce experience
- [x] Storefront, shop, product, collections
- [x] Cart and checkout demonstration
- [x] Customer/account demonstration
- [x] Order tracking demonstration
- [x] Responsive Tailwind implementation
- [x] SEO metadata
- [x] Buyer/rebranding documentation
- [ ] Replace emoji/demo visuals with properly licensed production imagery
- [ ] Expand product detail routing to the full catalogue
- [ ] Run local production build and lint
- [ ] Perform desktop/mobile visual QA
- [ ] Export to standalone repository
- [ ] Deploy to standalone transferable domain

## Listing accuracy
State clearly:
- Custom-built frontend/MVP
- No verified revenue unless evidence exists
- No verified traffic unless evidence exists
- Payment is simulated
- Authentication/customer persistence is simulated
- Inventory/fulfilment integrations are not live
- Buyer receives only the explicitly agreed code/domain/assets

## Before publishing a marketplace listing
Confirm licensing for every image, font, icon and third-party asset. Remove all credentials and environment secrets. Confirm which domain, repository and deployment are transferred. Capture screenshots only after standalone deployment and final QA.
